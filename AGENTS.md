# Agent instructions

[`CONTRIBUTING.md`](CONTRIBUTING.md) is the working agreement — the same file a
human contributor reads. It holds the gates, the test rules and the invariants,
and it says where a procedure or a record belongs. Read it before changing code.

This file exists because some tools look for this name. Keep it a pointer: a
rule added here would be a second copy, and the second copy is the one that
drifts.
